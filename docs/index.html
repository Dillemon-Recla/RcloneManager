Funcionalidades

Tudo o que você precisa para automatizar o Rclone no Windows

Projetado para unir a flexibilidade da linha de comando do Rclone com a praticidade de uma interface desktop e serviço persistente.

RC

Motor Híbrido (RC API + CLI)

Escolhe caso a caso entre CLI monitorada com --rc (ideal para --filter-from e --fast-list), daemon persistente rclone rcd na porta 5572 ou fallback CLI.

71+

Remotes Visuais (3 Modos)

Carrega os 71+ backends oficiais do Rclone. Crie, edite, teste conexão e autentique via Link OAuth, Token JSON ou Chave / Service Account.

AES

Cofre Windows & Exportação

Gera chave mestra AES-256 no Gerenciador de Credenciais do Windows. Exportações geram um blueprint portátil sem credenciais para reautenticação guiada no Wizard.

SHA

Auto-Download & Trava de Release

Baixa automaticamente a release travada (padrão v1.76.0) de fontes oficiais, valida o hash SHA-256 e impede execução caso haja divergência de versão.

24h

Agendador & Serviço Windows

Agende por intervalo, horário diário, dias da semana ou logon. Roda em 2º plano via --background, Registro Run ou como Windows Service nativo (sc.exe).

FLT

Otimizador de Filtros

Detecta conflitos entre --exclude-from e --filter-from, corrige precedência first-match-wins e extrai --max-size preservando backup .bak.

Arquitetura

Desacoplado em 3 Projetos (.NET 10 sem NuGet externos)

Mesmo ao fechar ou minimizar a interface WPF para a bandeja do sistema, o serviço de agendamento continua operando normalmente em segundo plano.

RcloneManager.UI

Interface WPF + Bandeja

First-Run Wizard, Dashboard ao vivo, Remotes, Editor de Filtros, Reset, Sobre e System Tray (net10.0-windows).

RcloneManager.Service

Daemon & API (:5580)

ASP.NET Core Kestrel local (127.0.0.1:5580), BackgroundService e dispatcher Windows Service via advapi32.dll.

RcloneManager.Core

Motor, Cofre & Scheduler

RcloneHybridEngine, JobScheduler, FilterFileHelper, RcloneReleaseManager e WindowsCredentialVault.

rclone.exe (v1.76.0)

Execução RC + CLI

Consultas via rclone rcd (:5572) e jobs de sincronização via CLI com porta RC dinâmica para estatísticas em tempo real.

Instalação & Uso

Início Rápido

Requer Windows 10/11 e .NET 10 SDK (ou Desktop + ASP.NET Core Runtime). Não precisa baixar o Rclone manualmente antes — o próprio app faz o provisionamento verificado por SHA-256.

PowerShell — Clonar, Compilar e Iniciar 
git clone https://github.com/Dillemon-Recla/RcloneManager.git
cd RcloneManager

# Compila os 3 projetos em modo Release (0 pacotes NuGet externos)
dotnet build RcloneManager.sln -c Release

# Abre a interface e sobe o serviço em segundo plano
.\Iniciar-RcloneManager.bat
1
Importar Config (Opcional) & Nova Chave

Gera sua chave AES-256 no Gerenciador de Credenciais do Windows ou importa um blueprint exportado.

2
Release Travada (SHA-256)

Verifica e baixa automaticamente o rclone.exe oficial na versão travada (v1.76.0).

3
Autenticar Serviços

Conecta seus remotes via Link OAuth no navegador, Token JSON ou Chave/Credenciais.

4
Revisar Tarefas & Agendador

Revise origem, destino, intervalo e ative a inicialização automática com o Windows.

Construído sobre o Rclone (Licença MIT)

O RcloneManager é uma interface independente desenvolvida sobre o Rclone, criado por Nick Craig-Wood e mantido pelos contribuidores da comunidade rclone/rclone sob a licença MIT.

Este projeto não possui afiliação oficial com os mantenedores do Rclone. Os binários oficiais baixados pelo provisionamento automático vêm diretamente das releases oficiais assinadas por SHA-256 do Rclone.
